# Fortune PDF Design System（現行 v2）

このファイルが、毎朝の占いPDFにおける現行 v2 の唯一の仕様である。日次占いは v2 を使う。
テンプレートは日次が `~/workspace/goals/goal-4/hidden_files/fortune-template-v2.html`（平日・休日共通、項目名もトークン）、週間ページは `fortune-template-v2-weekly.html` を正本とし、日付と占い内容だけを差し替える。

## v2 デザイン＆新構成（2026-10-27 本人確定・現行）

v7（スターバックス風グリーン）は旧版。日次占いは v2 を使う。

### デザイン（案D「クリア・モダン」＋H4ヘッダー）
- ベース色: 背景 #F5F7FA、本文 #000000（2026-10-28に #22303C から純黒へ変更・K2採用）、見出しネイビー #14324A、アクセント オレンジ #FF7A1A、ラベル青 #1C7FB8（補助要素のみ）
- ヘッダーは H4 型: 帯なし白背景、ブランド行はグレー #8CA0B0 の小文字、日付を 35px の特大タイポ、星とテーマはオレンジ、チップはネイビー地に白文字、下に 1px の淡い罫線
- 2・3ページ目の見出し: 白背景＋オレンジ 3px 下線
- カード: 白、角丸 14〜16px、影 0 1px 4px rgba(20,50,74,.10)
- 名言ブロック: ネイビー地 #14324A に白の明朝、著者はオレンジ #FFB37E
- アドバイス帯: オレンジ地に白文字

### 構成（全3ページ。月曜は週間ページを足して4ページ）
- 1ページ目: ヘッダー（日付・総合★・テーマ・チップ）／①今日の概要（全占いのアンサンブル、約300字）／②中項目×5（各150字まで）／今日の流れ（午前・午後・夜の3コマ）
- 2ページ目: ③四柱推命だけの今日の概要（約300字）／④四柱推命だけの中項目×5
- 3ページ目: ⑤四柱推命の今月の運気（約300字）／⑥四柱推命の今年の運気（約300字）／今月の流れ（週ごと・F4カレンダー帯型）／⑦今日の名言／ラッキーポイント／今日の一言
- 中項目の並び（平日）: 仕事・家族・ジム運・今日の注意・今日の天気。休日は「仕事」を外し、休息・楽しみ系に差し替える
- テンプレート: ~/workspace/goals/goal-4/hidden_files/fortune-template-v2.html（平日・休日共通、項目名もトークン）、週間ページは fortune-template-v2-weekly.html

### 今月の流れ（F4 カレンダー帯型）
- 週ごとに「色バー（週ラベル＋日付範囲）＋短文」の行で表す
- バーの色は週の重さで選ぶ: 重い週=赤 #B54434、やや重い=橙 #E08A2E、普通=黄 #C9A227、軽い・回復=青 #1C7FB8、特に良い=緑 #2E8B6E
- 週の区切りは暦週（その月の1日を含む週から）。節の切り替わり・冲の日・通変星の山谷を根拠にする

### 今日の名言（著者ローテーション拡大）
- ニーチェ／シオラン／ストア派（セネカ・マルクス・アウレリウス・エピクテトス）／ペシミズム系（ショーペンハウアー等）／吉田松陰／有名な禅僧（一休・道元・良寛・白隠など）の6系統から日替わりで選ぶ
- 実在の有名な言葉のみ。出典（著作名）を併記し、その日の運勢に結ぶ短いひと言を添える

### コンポーネント確定（2026-10-27 追加決定）
- 中項目は M3 アイコンカードで ②④共通: 白カード＋左5px色バー＋丸アイコン（一文字）。対応: 仕事=仕/#14324A、家族=家/#2E8B6E、ジム運=筋/#E08A2E、今日の注意=注/#B54434、今日の天気=天/#1C7FB8、休息と楽しみ=休/#8E6BC8
- 大項目（①③の概要と⑤⑥の箱）は O4 色パネル: 淡いグラデーション（#EAF1F7→#FDF0E4）＋1px枠 #D8E4EE＋角丸14px
- 今日の流れは T3 縦フロー: 白パネル内に丸ノード（朝=#E08A2E／昼=#1C7FB8／夜=#14324A）＋↓で連結
- 2ページ目下部に「命式コンテキスト」4タイル（日干／大運／今月／今日）を置く

### 項目タイトルの可読性改修（2026-10-28 本人指摘で A案 採用）
- 本人から「各項目のタイトルが小さくて薄い水色で見えにくい」と指摘。旧仕様（.slabel 10.5px・水色 #1C7FB8）は廃止
- 現行: .slabel は **14px・濃紺 #14324A・太字900・左にオレンジ6px縦バー＋padding-left 9px**（A案）。週間ページの .slabel も同じ
- 併せて命式タイルの小ラベル .tl は 11px・#14324A、週カードのタイトル .wt は 12.5px・#14324A に変更
- ラベルを大きくした分、1ページ目の余白を詰めて3ページ維持を確認済み（starsline/chips の margin、midgrid gap 6px、icard padding 5px、flow/vbody の padding、overview padding を微調整）。ページ数が増えたら文字ではなく余白で調整する
- 同日追加: 本文色も #22303C（青みグレー）→ **#000000 純黒（K2）** に変更（本体・週間とも）。命式コンテキスト下の注記 .ctxnote も #66766F → #444444 に濃くした

### 文字サイズ拡大（2026-10-31 本人指摘で確定・特大が最終形）
- 本人から「今朝の占いPDF、文字小さすぎて読めれん」と指摘。当初14.2px案（3ページ維持）を確定したが本人が「やっぱ小さい」と再指摘し、**特大案（本文16.5px・4ページ）が最終確定**
- 現行: **本文 16.5px**（行間1.56）、中項目 .mb 16.2px、今月/今年 .box p 15.9px、流れ .fb 15.4px、週バー .wb 15.1px、注記 .ctxnote 15.3px、名言ひと言 .qn 16px、項目名 .mt 15px、流れ見出し .ft・週見出し .wt 14.5px。週間ページも本文16.5px・表td 15.9px・box p 15.9px
- ページ数: 通常 **4ページ**、月曜は週間1ページを足して **5ページ**（cron本文の想定も更新済み）
- 余白は強めに圧縮してこのページ数に収めている: @page マージン 8mm/9mm（週間は7mm/9mm）、midgrid gap 4px、icard padding 3px 9px、overview padding 4px 11px 5px、flow padding 4px 11px 0、box padding 2px 9px 6px、quote padding 13px 15px、slabel margin 6px 0 3px、vbody padding-bottom 1px、crow margin-bottom 4px

## 継承要素（v2 と矛盾しないため存続）
- フォントは Noto Sans CJK JP。
- 四柱推命の通変星を軸にし、表面的な一言コメントで済ませない。
- 補足テキストも含め、背景に対して十分なコントラスト（目安 4.5:1）を確保する。
- 色や余白はテンプレート冒頭で意味のある名前で管理し、場当たり的な値を増やさない（トークン化）。
